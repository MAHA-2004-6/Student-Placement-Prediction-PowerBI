# 🎓 Student Placement Prediction & Analytics Dashboard

## 📌 Project Overview

The **Student Placement Prediction & Analytics Dashboard** is an interactive Power BI project developed to analyse student academic performance, skills, internships, projects, and other factors associated with placement outcomes.

The dashboard transforms a dataset of **100,000 student records** into meaningful visual insights that help understand placement performance and salary patterns.

The project focuses on three major areas:

- 📊 Placement Overview
- 📈 Placement Analysis
- 💰 Salary Analysis

The dashboard provides interactive filters, KPIs, charts, and insights to make student placement data easier to understand and analyse.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyse overall student placement performance.
- Identify placement rates across different branches.
- Understand the relationship between academic performance and placement.
- Analyse the impact of internships, projects, coding skills, and communication skills.
- Analyse salary packages of placed students.
- Identify salary patterns across different student categories.
- Build an interactive and user-friendly Power BI dashboard.
- Present complex placement data through clear and meaningful visualisations.

# 📊 Dashboard Structure

The Power BI dashboard contains three main pages.

---

## 1️⃣ Placement Overview

The **Placement Overview** page provides a high-level summary of student placement performance.

### Key KPIs

- Total Students
- Placed Students
- Placement Rate
- Average Salary of Placed Students

### Visualisations

- Placement Status Distribution
- Students by Branch
- Placement Rate by CGPA Range
- Students by Gender

### Key Insights

- **Total Students:** 100,000
- **Placed Students:** 54,459
- **Not Placed Students:** 45,541
- **Overall Placement Rate:** 54.46%
- **Average Salary among Placed Students:** approximately 13.32 LPA

---

## 2️⃣ Placement Analysis

The **Placement Analysis** page provides a deeper analysis of factors associated with student placement.

### Analysis Areas

- Placement Status by Branch
- Placement Rate by Internship Count

- Placement Rate by Coding Skill Range
- Placement Rate by Communication Score Range

### Key Insights

The dashboard allows users to examine how placement outcomes vary according to:

- Academic branch
- Internship experience
- Number of projects
- Coding skills
- Communication skills
- CGPA

### Example Insight

Students with internship experience showed a higher placement rate compared with students without internship experience in the analysed dataset.

# 🔍 Key Insights

Some of the major insights identified from the analysis include:

### 🏢 Branch Performance

Civil Engineering recorded the highest placement rate among the branches in the analysed dataset, at approximately **55.17%**.

### 🎓 CGPA & Placement

Students in the **9–10 CGPA range** recorded a placement rate of approximately **55.75%** in the analysed dataset.

### 💼 Internship Experience

Students with at least one internship showed a higher placement rate than students without internship experience.

### 💻 Technical & Communication Skills

The dashboard enables comparison of placement rates across different coding skill and communication score ranges.

### 💰 Salary Analysis

The salary analysis page provides an overview of salary distribution and allows comparison of average salary across different student characteristics.
